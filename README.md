# Daily Gourmet

Mandantenfähige Catering-Management-SaaS. Dieses Repository enthält nur das **Frontend**; das **Backend** lebt in einem eigenen Repository (siehe unten).

```
daily-gourmet/
├── frontend/   Next.js-Frontend (dieses Repo) — siehe frontend/README.md
└── backend/    .NET-Backend — eigenes Git-Repository, https://github.com/DevBerkcan/daily-gourmet-api
```

`backend/` ist im `.gitignore` dieses Repos ausgeschlossen, da es sein eigenes `origin` hat. Details zum Frontend: [frontend/README.md](frontend/README.md). Details zum Backend: [backend/README.md](backend/README.md) im Backend-Repo.
